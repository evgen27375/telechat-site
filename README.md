# TELECHAT — сайт-раздача

Лендинг для распространения Android-приложения **TELECHAT** (мессенджер на базе Telegram
со встроенным подключением, работает без VPN).

- `index.html` — статическая страница (весь стиль и логотип встроены, без внешних зависимостей).
- APK кладётся рядом как `telechat.apk` (в git не хранится; выкладывается при релизе).
  Скрипт `~/TELECHAT/toolchain/release-apk.sh` копирует свежий APK и проставляет его SHA-256 на странице.

Исходники приложения: https://github.com/evgen27375/telechat-android
